# Veilleur

A Discord bot written in Luau.

Veilleur is built on top of [DiscordLuau](https://github.com/DiscordLuau/discord-luau), a runtime-agnostic Luau library for creating Discord bots.

## Development

Veilleur is currently under active development. More documentation and bot functionality will be added as the project takes shape.
